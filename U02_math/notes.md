## 1. 矩阵乘法

### 维度规则（用自己的话写）
A.shape = (3, 4)
B.shape = (4, 2)
C = A@B = (3, 2)
A.shape = (m, n)
B.shape = (n, p)
C = A@B = (m, p)

### 和神经网络的关系
矩阵乘法是神经网络的基础
y = x@w + b
x输入层 (batch_size, input_dim)
w权重层 (input_dim, output_dim)
b (output_dim, )
y输出层 (batch_size, output_dim)

为什么用矩阵乘，一次并行算整个batch，GPU友好

## 2. 偏导数

### 一句话定义

函数把其他变量当成常数，对每个变量求导，得到的就是偏导数，
偏导数拼起来就是梯度

### 数值微分和解析微分的区别
数值微分是将函数自变量变化增加一个极小值，看函数值变化
解析微分是直接公式求导

## 3. 链式法则

### 核心公式

z1 -> a1 -> z2 -> L
dL_dw1 = dL_dz2 · dz2_da1 · da1_dz1 · dz1_dw1
= (z2-y) · w2 · a1(1-a1) · x



### 为什么反向传播需要它
反向传播，利用链式法则求出loss对于每一个参数的导数
