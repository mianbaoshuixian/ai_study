## 这部分在面试中的重要程度

Transformer 是 2024 年以后**算法岗与大模型岗的绝对核心八股**，几乎是必考、且常被反复深挖的板块。重要程度可分三档：

- **必背高频（几乎每场都问）**：Self-Attention 计算流程、为什么除以 √dk、多头注意力的目的、位置编码为什么必要、Encoder/Decoder 交互。字节、阿里、腾讯标注为「高频」。
- **进阶区分度（面试官筛人用）**：Q/K 为什么用不同权重、点积 vs 加性、LayerNorm 为什么不用 BatchNorm、Mask 的两种类型、O(n²) 复杂度及其后果。
- **加分项（拉开差距）**：embedding 乘 √d_model 的原因、Pre-Norm vs Post-Norm、RoPE 相对 PE 的优势、Decoder-only 为什么成为主流、长上下文「中间迷失」。

出题逻辑通常是**「先问 what，再追问 why，最后问 trade-off / 工程影响」**。能答出 why 和 trade-off 的人，才是面试官想要的。

## Q1. 手推 Self-Attention 的完整计算过程

**【考点】** Scaled Dot-Product Attention 的数学流程、各张量形状、对公式的真实理解。

**【出题意图】** 这是 Transformer 的地基题，几乎 100% 出现。面试官想确认你不是只会背 `softmax(QKᵀ/√dk)V` 这一行，而是能讲清每一步张量怎么变、每个矩阵的物理含义。答不清楚直接出局。

**【详细解题过程】** 设输入序列表示为 `X`，形状 `(n, d_model)`，n 为序列长度。

1. **生成 Q/K/V**：用三个可学习权重矩阵线性投影
   - `Q = X·Wq`，`K = X·Wk`，`V = X·Wv`，形状均为 `(n, d_k)`（V 可为 `d_v`，通常相等）。
   - 含义：Q 是「当前位置想找什么」，K 是「每个位置能提供什么标识」，V 是「每个位置实际携带的信息」。
2. **算相关性分数**：`scores = Q·Kᵀ`，形状 `(n, n)`。`scores[i,j]` 表示位置 i 对位置 j 的关注强度。点积越大越相关。
3. **缩放**：`scores = scores / √dk`，防止高维下点积方差过大（见 Q2）。
4. **（可选）Mask**：Decoder 把未来位置、PAD 位置置 `-∞`。
5. **softmax 归一化**：对每一行做 softmax，得到权重矩阵 `(n, n)`，每行和为 1。
6. **加权求和**：`output = weights·V`，形状 `(n, d_v)`，即每个位置融合全序列信息后的新表示。

完整公式：`Attention(Q,K,V) = softmax(QKᵀ/√dk)·V`。逐步图解见详尽版 Q1。

**【答题思路】** 边写公式边报形状（`(n,d)→(n,n)→(n,d)`），并用「Q找对象 / K判断匹配 / V提供内容」这组比喻收尾。主动补一句「缩放和 Mask 是两个易被追问的点」，引导面试官往你准备好的方向问。

## Q2. 为什么 softmax 前要除以 √dk？不缩放会怎样？（要求推导）

**【考点】** 点积的方差性质、softmax 的梯度饱和。

**【出题意图】** 区分「背过」和「懂原理」的经典追问题。能否做出方差推导，是算法岗的硬门槛。

**【详细解题过程】**

- 假设 q、k 各维度独立、均值 0、方差 1。点积 `q·k = Σ qᵢkᵢ`（共 dk 项）。
- 每一项 `qᵢkᵢ` 的均值为 0，方差为 1；dk 个独立项求和后，**均值仍为 0，方差变为 dk**。
- 所以点积标准差约为 `√dk`。dk 越大（如 64、128），分数数值越大、越分散。
- 数值过大送入 softmax，会让最大那项概率趋近 1、其余趋近 0（接近 one-hot）。此时 softmax 进入**饱和区**，其雅可比矩阵元素趋近 0，反向传播**梯度消失**，模型难以训练。
- 除以 `√dk` 后，点积方差被拉回约 1，softmax 输出平滑、梯度健康。

**【答题思路】** 先抛结论「为了让点积方差回到 1，避免 softmax 梯度消失」，再做 `Var(Σqᵢkᵢ)=dk → 标准差√dk` 的推导，最后点明「不缩放 → softmax 饱和 → 梯度趋0 → 训不动」的因果链。

## Q3. 为什么 Q 和 K 要用不同的权重矩阵？能否共享、或拿 K 和自己点乘？

**【考点】** 注意力矩阵的对称性、表达能力与泛化。

**【出题意图】** 看你是否理解 Q、K 的「角色解耦」。很多人能背 Q/K/V，但说不清为什么不能合并——这正是面试官想抓的薄弱点。

**【详细解题过程】**

- 若 Q、K 用同一矩阵（即 `K·Kᵀ`），得到的注意力分数矩阵是**对称矩阵**（`score[i,j]=score[j,i]`）。但语言中「i 关注 j」和「j 关注 i」往往不对称（如代词指代是单向的），对称性会严重限制表达。
- 共享权重还意味着 Q、K 投影到**同一子空间**，「查询角色」和「被检索角色」无法分化，泛化能力差。
- 用不同的 `Wq`、`Wk`，把输入投到两个不同子空间：Q 表达「我在找什么」，K 表达「我能被什么找到」，二者解耦后注意力分布更灵活、表达力更强。

**【答题思路】** 一句话核心：「共享会让 score 矩阵对称、投影到同一空间，丢掉方向性和表达力」。补一个不对称的语言例子（指代/因果）增强说服力。

## Q4. 多头注意力的设计目的是什么？为什么每个头要降维？

**【考点】** 多子空间建模、参数量与计算量的平衡。

**【出题意图】** 高频题。考你是否理解「多头不是为了堆算力，而是为了多视角」，以及降维背后的工程权衡。

**【详细解题过程】**

- **目的**：单头注意力只能学一种关系模式；语言里同时存在语法、语义、指代、共现等多种依赖。多头用 h 组独立的 `Wq/Wk/Wv` 投影，让不同头各自关注不同子空间的关系，最后拼接融合，提升表达能力（类比 CNN 多通道）。
- **为什么降维**：每个头的维度取 `d_model/h`，h 个头拼接后恰好还原为 `d_model`。这样**总计算量与参数量约等于单头全维**，用几乎相同的成本换来了多视角能力。
- **流程**：拆分维度 → h 个头并行算 Scaled Dot-Product Attention → 沿特征维拼接 → 乘 `Wo` 融合输出。公式 `MultiHead = Concat(head₁..head_h)·Wo`。

**【答题思路】** 「多头 = 多个低维子空间并行 + 拼接融合」，强调降维是为了「在不增加计算量的前提下获得多视角」。结尾点出 `Wo` 的融合作用，很多人会漏。

## Q5. 为什么用点积注意力而不是加性注意力？

**【考点】** 点积 vs 加性（Bahdanau）注意力的复杂度与工程效率。

**【出题意图】** 承接 U11 学过的 Bahdanau 加性注意力，考你能否横向对比，理解 Transformer 的工程取舍。

**【详细解题过程】**

- **加性注意力**（Bahdanau）：`score = vᵀ·tanh(Wq·q + Wk·k)`，引入额外参数和非线性。
- **点积注意力**：`score = q·k / √dk`，无额外参数。
- 理论复杂度二者相近，但点积可写成**大矩阵乘法 `QKᵀ`**，能充分利用 GPU 的高度优化的矩阵乘法内核，**实际速度快很多、更省显存**。
- 论文实验：dk 较小时两者效果相当；dk 大时不缩放的点积会变差，于是 Transformer 选择「点积 + √dk 缩放」兼顾速度与稳定。

**【答题思路】** 关键词是「点积能转成矩阵乘法、GPU 友好」。可顺势对比 U11 的 Bahdanau 公式，体现你有连贯的知识脉络（面试官喜欢这种）。

## Q6. Decoder 里两种 Mask（Padding Mask、Look-Ahead Mask）的区别与作用？

**【考点】** 因果掩码与填充掩码、训练并行与推理一致性。

**【出题意图】** 考你是否理解「训练时并行、却又不能偷看未来」这个核心矛盾的解法。能区分两种 mask 的人不多。

**【详细解题过程】**

- **Padding Mask（填充掩码）**：屏蔽 `<pad>` 位置，避免注意力关注无意义填充。形状 `(b, seq_len)`，Encoder/Decoder 只要有 PAD 都需要。实现：把 PAD 列的分数置 `-∞`。
- **Look-Ahead Mask（因果/未来掩码）**：只用于 Decoder 的 self-attention。为了让训练时并行预测每个位置，又不泄露未来词，把分数矩阵的**上三角（未来位置）置 -∞**，形成下三角可见结构。
- 二者都通过「置 -∞ → softmax 后趋 0 → 加权和几乎不含被屏蔽信息」生效，常叠加使用。

**【答题思路】** 用一句话点破动机：「并行训练 + 自回归约束」的矛盾靠 Look-Ahead Mask 解决；PAD Mask 是处理变长 batch 的。配合下三角图最直观。

## Q7. Encoder 和 Decoder 之间是如何交互的？

**【考点】** Cross-Attention（编码器-解码器注意力）的 Q/K/V 来源。

**【出题意图】** 考整体架构理解，也是连接「Seq2Seq Attention」与「Transformer」的桥梁题。

**【详细解题过程】**

- Encoder 把源序列编码为 `memory`，形状 `(b, src_len, d_model)`。
- Decoder 每层有一个 **Cross-Attention 子层**：
  - **Q 来自 Decoder**（当前生成状态，经过 Masked Self-Attn 后的表示）；
  - **K、V 来自 Encoder 的 memory**（整个源序列上下文）。
- 即「用当前要生成的词去询问源句哪些位置最相关」，本质等价于 Seq2Seq 中的 Attention 机制，只是放进了 Transformer 框架。

**【答题思路】** 死记一句：「Cross-Attn 的 Q 来自解码端，K/V 来自编码端」。再点明它就是 U10/U11 学的 Seq2Seq Attention 的「Transformer 版本」，体现知识贯通。

## Q8. 为什么用 LayerNorm 而不是 BatchNorm？它在 Transformer 的哪个位置？

**【考点】** 两种归一化的方向差异、对变长序列与推理一致性的影响。

**【出题意图】** 区分度很高的题。能从「归一化方向 + 变长 + batch 敏感 + 推理一致」多角度回答的人，明显更扎实。

**【详细解题过程】**

- **方向差异**：BatchNorm 沿 batch 维（对每个特征跨样本）归一；LayerNorm 沿特征维（对单个 token 的所有特征）归一。
- **为什么 NLP 选 LN**：
  1. **变长序列**：句子长度不一，不同位置 token 语义分布不同，对位置维做 BN 理论上不合理；
  2. **batch 敏感**：BN 依赖较大 batch 估计稳定统计量，NLP 受显存限制 batch 常较小，BN 统计量不稳；
  3. **推理一致性**：BN 推理用训练期累积的全局均值/方差，自回归逐 token 生成时不准；LN 只依赖当前样本，训练/推理行为一致。
- **位置**：每个子层（Self-Attn / FFN）之后，配合残差：`output = LayerNorm(x + Sublayer(x))`（原始 Post-Norm）。

**【答题思路】** 先讲「方向不同」这个本质，再用「变长 / 小 batch / 推理一致」三连击。加分项：提一句现代大模型多用 Pre-Norm（`x + Sublayer(LN(x))`）训练更稳，甚至 RMSNorm。

## Q9. 位置编码为什么必要？正弦余弦编码有什么优点？还知道哪些位置编码？

**【考点】** 自注意力的排列等变性、正余弦 PE 的设计、PE 技术演进。

**【出题意图】** 高频题。先考「为什么需要」，再追问「还知道哪些」来探边界（RoPE 是当前热点）。

**【详细解题过程】**

- **为什么必要**：Self-Attention 是**排列等变**的——打乱输入顺序，输出只是相应重排，语义表示不变。所以它天生分不清「猫吃鱼」和「鱼吃猫」。必须显式注入位置信息。
- **正弦余弦编码**：`PE(pos,2i)=sin(pos/10000^(2i/d))`，`PE(pos,2i+1)=cos(...)`，与词向量相加。
  - 优点：无需训练、可预计算；值域 `[-1,1]` 数值稳定；同一位置在不同句长下编码一致；不同位置间有线性关系，便于模型感知相对位置；理论上可外推到训练未见长度。
- **其它方案**：
  - 可学习位置编码（BERT）：灵活贴合数据，但无法外推超训练长度；
  - 相对位置编码（T5/Transformer-XL）：直接建模相对距离，对位置敏感任务更好，但实现复杂；
  - **RoPE 旋转位置编码**（LLaMA/ChatGLM/GPT 系）：通过旋转把相对位置融入注意力，外推能力强，是当前主流。

**【答题思路】** 第一句必须是「自注意力排列等变 → 没有位置信息」。正余弦讲「固定、稳定、可外推、含相对关系」四个优点。结尾主动提 RoPE，展示你跟进了前沿。

## Q10. FFN 的结构是什么？为什么是「两层全连接 + ReLU」？

**【考点】** 前馈子层结构、升维-激活-降维的作用。

**【出题意图】** 考细节完整度。FFN 常被忽视，但面试官用它检查你是否真的把一层 Transformer 看全了。

**【详细解题过程】**

- 结构：`FFN(x) = W2·ReLU(W1·x + b1) + b2`，先升维再降维。中间维 `d_ff` 通常是 `d_model` 的 4 倍（如 512→2048→512）。
- 作用：
  1. 注意力子层本质是 V 的**线性加权**，缺少非线性；FFN 用 ReLU 引入非线性，增强表达能力。
  2. 升维到 `d_ff` 提供更大的特征空间做变换，再降回 `d_model` 保持维度一致以便堆叠。
  3. FFN 是**逐位置（position-wise）独立**的：对每个 token 用同一套权重单独变换，不跨位置混合（混合交给注意力做）。

**【答题思路】** 强调两点：FFN 给模型补「非线性」，且是「逐位置共享权重」。提一句现代模型常把 ReLU 换成 GeLU/SwiGLU 是加分项。

## Q11. 为什么取词向量后要乘以 √d_model？残差连接的意义是什么？

**【考点】** embedding 缩放的初始化动机、残差对梯度的作用。（两个细节合并考）

**【出题意图】** 这是「魔鬼细节」题，专门用来区分顶尖候选人。能答出 embedding 乘 √d_model 的几乎都是认真读过实现的人。

**【详细解题过程】**

- **embedding 乘 √d_model**：embedding 常用接近 `Var≈1/d_model` 的方式初始化，数值偏小。乘上 `√d_model` 把其方差拉回约 1，使**词向量与位置编码（值域 [-1,1]）数量级相当**，相加时词义信息不会被位置编码淹没，也利于收敛。
- **残差连接** `y = x + Sublayer(x)`：
  1. 反向传播时梯度可经恒等路径直接回传，**缓解深层网络梯度消失**；
  2. 让每个子层只需学习「相对输入的增量」，优化更容易；
  3. 是 Transformer 能堆叠 6~100 层的关键结构。

**【答题思路】** embedding 缩放讲「让词向量方差≈1，和位置编码量级匹配」；残差讲「给梯度一条恒等高速路，支撑深层堆叠」。两个都是细节分，答出即加分。

## Q12. Transformer 的复杂度是多少？带来哪些工程局限？如何缓解？

**【考点】** O(n²) 自注意力复杂度、长上下文问题、应用层应对。

**【出题意图】** 偏应用/系统的综合题，大模型应用开发岗尤其爱问。考你是否理解架构特性如何映射到真实工程约束。

**【详细解题过程】**

- **复杂度**：自注意力需算 `QKᵀ`，所有位置两两交互，时间和显存均为 **O(n²·d)**，n 为序列长度。
- **由此引出的局限**：
  1. **上下文窗口有硬上限**：n 翻倍，注意力开销变 4 倍，长度不能无限扩；
  2. **位置编码外推问题**：训练没见过的更长位置表示不可靠，长文质量下降；
  3. **中间迷失（Lost in the Middle）**：模型对输入中段信息关注度低于首尾；
  4. **生成串行**：Decoder 自回归逐 token 生成，速度有上限。
- **缓解手段**：稀疏/滑窗注意力、FlashAttention（省显存、不改结果）、RoPE/YaRN 扩展位置外推、投机解码（Speculative Decoding）加速生成；应用层把关键信息放 Prompt 首尾、做上下文管理、流式返回。

**【答题思路】** 先给 O(n²) 这个锚点，再顺着它推出「窗口上限 / 外推 / 中间迷失 / 串行生成」四个后果，最后分「模型层」和「应用层」两类给缓解方案。这种「原理→后果→对策」的结构最能打动面试官。
